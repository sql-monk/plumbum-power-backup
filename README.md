# ESP8266 Battery Charger Controller

Інтелектуальна система керування зарядкою свинцевих акумуляторів на базі ESP8266 з використанням лабораторного блоку живлення DPS5015.

## Можливості

- ⚡ Автоматичний 3-стадійний алгоритм зарядки (Bulk/Absorption/Float)
- 🌡️ Температурна компенсація напруги зарядки
- 📊 Веб-інтерфейс для моніторингу та керування
- 🔌 Підтримка DPS5015 через Modbus RTU
- 📈 Точний моніторинг напруги (INA219) та струму (ACS711)
- 🌡️ Моніторинг температури батареї (до 2x DS18B20)
- 🎮 Керування GPIO виходами (реле, тощо)
- 🕐 Синхронізація часу через NTP

## Апаратна частина

### Мікроконтролер
- **ESP8266** (NodeMCU v3 або аналог)
- **WiFi**: 2.4GHz, статична IP: 192.168.50.82

### Периферія

| Пристрій | Інтерфейс | Піни ESP8266 | Призначення |
|----------|-----------|--------------|-------------|
| DPS5015 | Modbus RTU (9600 baud) | D7 (TX), D8 (RX) | Блок живлення |
| INA219 | I2C (0x40) | D1 (SCL), D2 (SDA) | Вимір напруги батареї |
| ACS711 | Analog | A0 | Вимір струму батареї (±15.5A) |
| DS18B20 (x2) | 1-Wire | D6 | Температура батареї |
| Реле | GPIO | D3 | Вихідний пін керування |
| GPIO | GPIO | D4, D5 | Додаткові виходи |

## Встановлення

### Необхідні бібліотеки

Встановіть наступні бібліотеки через Arduino Library Manager:

```
- ESP8266WiFi (вбудована)
- ESPAsyncWebServer (https://github.com/me-no-dev/ESPAsyncWebServer)
- ESPAsyncTCP (https://github.com/me-no-dev/ESPAsyncTCP)
- Wire (вбудована)
- Adafruit INA219
- OneWire
- DallasTemperature
- ModbusMaster
```

### Налаштування

1. Відкрийте файл `esp-web/config.h`
2. Налаштуйте WiFi:
   ```cpp
   #define WIFI_SSID "YourSSID"
   #define WIFI_PASSWORD "YourPassword"
   ```
3. За необхідності змініть IP адресу:
   ```cpp
   #define STATIC_IP IPAddress(192, 168, 50, 82)
   ```

### Завантаження

1. Підключіть ESP8266 до комп'ютера
2. Відкрийте `esp-web/esp-web.ino` в Arduino IDE
3. Виберіть плату: **NodeMCU 1.0 (ESP-12E Module)**
4. Виберіть порт
5. Завантажте скетч

## Використання

### Веб-інтерфейс

Після завантаження та підключення до WiFi, відкрийте у браузері:
```
http://192.168.50.82/
```

### Функції інтерфейсу

**DPS Power Supply Block:**
- Статус підключення DPS5015
- Вхідна та вихідна напруга/струм
- Встановлені параметри
- Кнопка ON/OFF для вимикача виходу

**Battery Status Block:**
- Напруга батареї
- Струм батареї (+ зарядка, - розрядка)
- Температура 1 та 2
- Середня температура та температурна компенсація
- Поточний стан (STANDBY/CHARGING/DISCHARGING/DISCONNECTED/ERROR)

**Control Panel:**
- **Charge Settings**: налаштування напруги та струму для режимів Bulk та Standby
- **GPIO Control**: керування виходами D3, D4, D5
- Uptime та поточний час (NTP)

### Алгоритм зарядки

Система автоматично переключається між режимами:

1. **DISCONNECTED**: батарея не підключена або напруга < 3V
   - Встановлюється standby напруга

2. **CHARGING** (Bulk): активна зарядка
   - Умова входу: напруга < 25V або струм ≥ 0.2A
   - Напруга: 28.4V (з температурною компенсацією)
   - Струм: до 7A (максимальний)

3. **STANDBY** (Float): підтримка заряду
   - Умова: напруга ≥ 25V і струм < 0.2A протягом 15 секунд
   - Напруга: 27.2V (з температурною компенсацією)

4. **DISCHARGING**: розрядка батареї
   - Умова: струм < -0.02A (негативний)
   - Встановлюється standby напруга

### Температурна компенсація

Формула: `V_comp = V_base + (T - 25°C) × (-0.036 V/°C)`

- При підвищенні температури напруга зарядки знижується
- При зниженні температури напруга зарядки підвищується
- Максимальна напруга обмежена 29.0V

### API Endpoints

- **GET /** - головна сторінка (HTML)
- **GET /data** - поточні дані системи (text/plain, оновлюється кожну секунду)
- **GET /cmd** - виконання команд

**Команди:**
```
/cmd?action=dps_output_on           - увімкнути вихід DPS
/cmd?action=dps_output_off          - вимкнути вихід DPS
/cmd?action=set_charge_voltage&value=28.4   - встановити напругу зарядки
/cmd?action=set_charge_current&value=7.0    - встановити струм зарядки
/cmd?action=set_standby_voltage&value=27.2  - встановити standby напругу
/cmd?action=set_standby_current&value=7.0   - встановити standby струм
/cmd?action=toggle_pin&pin=d3       - перемкнути GPIO (d3, d4, d5)
```

## Безпека

### Захист від перенапруги
- Максимальна напруга обмежена 29.0V в конфігурації

### Захист від перевантаження по струму
- Максимальний струм 7.0A в конфігурації
- Можна налаштувати через веб-інтерфейс

### Моніторинг температури
- Валідні значення: 0-50°C
- При виході за межі використовується референсна температура 25°C

## Діагностика

### Serial Monitor (115200 baud)

Система виводить діагностичну інформацію:
- Етапи ініціалізації
- Статус підключення WiFi та IP адресу
- Кількість знайдених температурних датчиків
- Статус підключення до DPS5015 та INA219
- HTTP запити до веб-сервера
- Переходи між станами автопілота

### Glow ефекти

Блоки у веб-інтерфейсі мають візуальну індикацію стану:

**DPS Block:**
- 🟢 Зелений: підключено
- 🔴 Червоний: не підключено

**Battery Block:**
- 🔵 Синій: зарядка (CHARGING)
- 🟠 Помаранчевий: розрядка (DISCHARGING)
- 🟢 Зелений: standby (STANDBY)
- 🔴 Червоний: помилка або відключено (ERROR/DISCONNECTED)

## Налаштування параметрів

### config.h

Всі основні параметри знаходяться у файлі `config.h`:

```cpp
// Параметри зарядки для 24V системи
#define BULK_VOLTAGE_BASE 28.4     // Напруга bulk зарядки
#define STANDBY_VOLTAGE_BASE 27.2  // Напруга standby
#define LOW_VOLTAGE_THRESHOLD 25.0 // Поріг активації зарядки
#define ABSORPTION_CURRENT 0.2     // Поріг струму для absorption
#define MAX_VOLTAGE 29.0           // Максимальна напруга
#define MAX_CURRENT 7.0            // Максимальний струм
#define TEMP_COEFFICIENT -0.036    // Коефіцієнт для 24V системи
#define REFERENCE_TEMP 25.0        // Референсна температура
```
